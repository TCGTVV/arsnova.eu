# Pre-Flight-Checkliste — vor jeder Sitzung

Vor **jeder** der beiden Sitzungen abzuarbeiten. Pro Sitzung eine eigene Kopie ausfüllen.

- **Rolle dieser Sitzung:** ☐ Quizmaster ☐ Quizteilnehmer/in
- **Datum / Uhrzeit:** **********\_\_**********
- **Tool:** ☐ Teams ☐ Zoom

## A. Technik

- [ ] Teams-/Zoom-Termin angelegt, Einladung an die Testperson verschickt
- [ ] Audioaufnahme im Tool getestet (Aufnahme startet, Ton ist verständlich)
- [ ] Bildschirmfreigabe funktioniert (Testperson teilt den **getesteten** Browser)
- [ ] Mikrofon/Headset auf beiden Seiten geprüft, keine starken Störgeräusche
- [ ] Stabile Internetverbindung beidseitig
- [ ] Speicherort für Audiodateien festgelegt, Dateinamensschema bekannt

## B. Geräte & Browser

- [ ] **Quizmaster-Aktionen:** Desktop-Browser bereit
- [ ] **Quizteilnehmer/in-Rolle:** Smartphone-Browser bereit
- [ ] Zweiter Zugang/Gerät für die **Gegenrolle der Testleitung** bereit
  - Quizmaster-Session: Testleitung tritt im **Smartphone-Browser** als Teilnehmer/in bei
  - Quizteilnehmer-Session: Testleitung hostet im **Desktop-Browser** als Quizmaster
- [ ] Aktueller Browser auf allen Geräten

## C. arsnova.eu (Produktion)

- [ ] <https://arsnova.eu> auf allen beteiligten Geräten erreichbar
- [ ] **Update-Hinweis** akzeptiert, falls angezeigt (aktuelle Version nutzen)
- [ ] **Preset „Spielerisch"** aktiv geprüft; falls anderer Stil aktiv → vor Testbeginn auf „Spielerisch" wechseln
  - Hinweis: „Spielerisch" ist der Default beim Erstbesuch; nur ein zuvor gespeicherter Stil müsste zurückgestellt werden.

## D. Rollenspezifische Produktkonfiguration

### Quizmaster-Session

- [ ] Testperson legt das Quiz **selbst** an (kein vorbereitetes Quiz nutzen)
- [ ] Sollwerte zur Beobachtung (nicht vorsagen): **Im Team spielen**, **2 Teams**, Teilnahme mit Pseudonym, Set **Kindergarten (Tier-Emojis)**
- [ ] 1 Single-Choice-Frage (4 Optionen, genau 1 richtig) + 1 Multiple-Choice-Frage (4 Optionen, ≥ 2 richtig)
- [ ] Mind. 2 Markdown-Funktionen in den Fragetexten (z. B. Bild, Liste, Code, Link, Formel, Vorschau)

### Quizteilnehmer/in-Session

- [ ] Demo-Quiz **„Praxis-Showcase: Team-Quiz" (9 Fragen)** in der Quizsammlung verfügbar
  - Wird beim ersten Start ohne vorherige Nutzung angeboten; bei Bedarf vorher prüfen, dass es als Demo-Karte erscheint.
- [ ] Demo-Quiz bringt 2 Teams + Kindergarten-Pseudonyme bereits mit (keine Zusatzkonfiguration nötig)
- [ ] Testleitung kann die Sitzung im Desktop-Browser hosten und alle 9 Fragen durchführen
